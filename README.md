# ria-platform

An investment-adviser (RIA) platform: a FastAPI back end, a React + TypeScript web app, and PostgreSQL.
It is at the starter-app stage.

Quick start (needs Docker, Python 3.12+ and Node 24):

```bash
./dc up            # start everything, then open http://127.0.0.1:5173
./dc check quick   # run the checks
./dc down          # stop
```

Everything else (layout, commands, tests, conventions) is in [docs/development.md](docs/development.md).
